# 1.指纹检测：
作用：快速检测训练集和测试集是否存在输入完全相同的记录
02的做法：
1.将每个记录的38列输入值看作一个整体，称为"输入指纹"
2.对比测试机和训练集的指纹，观察是否有重复
3.对相同指纹记录逐列核对，看是否真的完全相同

# 2.独热编码：
作用：去掉标签数字大小对没有数量大小关系的记录的影响
02的做法：
1.将类别列进行独热编码
2.1代表属于这个类别，0代表不属于（所以每一列只有一个1，其他全是0）

# 3.Min-Max转换：
作用：除去数值尺度，单位等影响，把大小不一的数值都放在0-1里面，方便模型输入等
      同样可以检查数据长尾分布情况
02的做法：
1.最小的数值=0，最大的数值=1
2.其余的值=（原始值-最小值）/（最大值-最小值）
3.以训练数据已经Min-Max转换后的基础，再对测试数据进行转换

# 固定随机种子：
作用：让程序能够在相同算法，数据集等情况下，能够复查
02的做法：
1.让训练集和测试集随机分组（80%+20%）
2.让数据集分成五份，每一份都划分测试集和训练集，形成五个候选划分情况（生成五折候选，每个候选集的总数量和初始数量集一样）

# 隔离划分
作用：使完全相同列划分在一个数据集里面
02的做法：
1.完全相同的列要么在测试集，要么在训练集
